# 🛒 Amazon Customer Analysis Dashboard

An end-to-end **Data Analytics Project** built using **Python, PostgreSQL, SQL, and Power BI** to analyze **1 Million Amazon E-commerce Transactions** and generate business insights through an interactive dashboard.

---

## 📌 Project Overview

In today’s competitive e-commerce environment, businesses need to understand customer behavior, sales trends, return patterns, and seller performance to make data-driven decisions.

This project transforms raw transactional data into actionable insights using a complete analytics workflow:

**Raw Data → Cleaning → SQL Analysis → Dashboard Visualization**

---

## 🎯 Objectives

This project aims to answer key business questions such as:

- Which categories generate the highest revenue?
- Which cities contribute the most sales?
- What is the product return rate?
- Which devices do customers use most?
- How are monthly sales performing?
- Which sellers perform best?

---

## 🧹 Data Cleaning (Python)

Performed the following preprocessing steps:

- Loaded raw CSV data using Pandas
- Checked missing values
- Filled null seller ratings using median
- Renamed inconsistent columns
- Converted purchase date to datetime format
- Removed duplicates
- Prepared clean dataset for SQL & Power BI
